# 需求解析测试集：怎么写

测试集由组员亲手写，**不能用任何大模型生成或改写**。写好后定稿，训练和调参之前就不再改。

复制 `test_template.csv`，另存为 `test.csv`（同一个文件夹），删掉 10 个示例行再写。示例只是格式样板，不进测试集。目标 100–150 句，中文、英文、中英混合都要有。

## 一行是什么

一行是一个**短句**（clause）。一句话切成几个短句就写几行；同一句话的第二行起，`sentence_id` 和 `sentence` 可以留空。

| 列 | 写什么 |
| --- | --- |
| `sentence_id` | 句子编号，如 `s001` |
| `sentence` | 学生的原话，照抄，不要改 |
| `clause` | 你切出来的短句，从原话里原样截取 |
| `label` | 9 类之一（见下） |
| `block` | 不能上课的时间，只有 `blocked_time` 填 |
| `max_days` | 每周最多到校几天，整数 |
| `max_class_hours` | 每天最多**上课**几小时，可以写 4.5 |
| `max_campus_hours` | 每天最多**在校**几小时（第一节课到最后一节课） |
| `lunch` | 午饭：`时段 分钟`，如 `11:30-14:00 30` |
| `prefer_hours` | 软性的舒服时段，如 `10:00-18:00` |
| `note` | 备注，随便写 |

`cares`（在意天数／等待／早晚）和"只要线下课"不用填，由类别决定。

## 9 个类别

| 类别 | 意思 | 例子 |
| --- | --- | --- |
| `blocked_time` | 说出了星期几、钟点，或者某段时间有事（打工、接送孩子、训练、宗教、通勤） | 周五要打工；十点前没法上课；我不想周一上课 |
| `max_days` | 说了每周到校的**天数** | 一周最多来三天 |
| `max_daily_hours` | 说了每天的**小时数** | 每天上课别超过五小时 |
| `lunch` | 要留时间吃午饭 | 中午要留时间吃饭 |
| `in_person_only` | 只要线下课，不要网课 | 不要网课 |
| `prefer_fewer_days` | 想少去几天、课排集中，但没说数字也没说哪天 | 课尽量集中 |
| `prefer_less_waiting` | 不想课之间等太久 | 不想课之间空太久 |
| `prefer_no_early_late` | 笼统地不喜欢早课或晚课；或者用"最好／尽量／prefer"说了个钟点 | 早上起不来；最好十点以后再上课 |
| `other` | 排课程序管不了的，或者没提要求 | 想和室友一个 tutorial；都可以 |

## 拿不准时按这个顺序判断（先对上哪条就用哪条）

1. 说吃饭 → `lunch`，就算带了时间（"12 点到 1 点要吃饭"）。
2. 不要网课 → `in_person_only`；想要网课 → `other`。
3. 说了天数 → `max_days`；说了每天小时数 → `max_daily_hours`。带"最好"也一样。
4. 说了星期几、钟点，或"某段时间有事" → `blocked_time`，**语气软硬不影响**（"不想周一上课"也算）。
5. 例外：用"最好、尽量、如果可以、希望、prefer、ideally、if possible、rather"说了一个钟点，而且没说星期几、没说有什么事 → `prefer_no_early_late`，把时段写进 `prefer_hours`。
6. 只说早上起不来、不是早起的人，没有钟点 → `prefer_no_early_late`，`prefer_hours` 留空。
7. 想少去几天、课集中，没数字没星期 → `prefer_fewer_days`。
8. 课之间的空档、等待、想连着上 → `prefer_less_waiting`。
9. 其他 → `other`。

## 怎么切短句

- 一个短句只放一个要求。用逗号、句号、"而且／但是／and／but"分开的不同要求，各写一行。
- 回指前面的部分留在同一个短句里："我周五打工，所以那天不行""周二周四有空，其他天都不行""I work Mon, Wed and Fri"。
- 原因和结果放一起："因为要送孩子，早上九点半以前不行"。
- "谢谢""你好"这类客套话不写。

## `block` 怎么写

- 格式：`星期 时段`，多段用分号隔开：`Fri all; Mon-Fri 0:00-10:00`
- 星期用英文缩写 `Mon Tue Wed Thu Fri Sat Sun`；几天用逗号 `Tue,Thu`，连续几天用横线 `Mon-Fri`。
- 时段用 24 小时制 `开始-结束`，一整天写 `all`，到半夜写 `24:00`。

统一的默认值（照这个写，模型才有对错可比）：

| 学生说的 | 写成 |
| --- | --- |
| 只说星期，没说时间 | 那天 `all` |
| 只说时间，没说星期（含"每天"） | `Mon-Fri` |
| 早上／morning | `0:00-10:00` |
| 上午 | `0:00-12:00` |
| 中午 | `12:00-14:00` |
| 下午／afternoon | `12:00-18:00` |
| 晚上／evening／night | `18:00-24:00` |
| X 点前不行 | `0:00-X` |
| X 点后不行／X 点后有事 | `X-24:00` |
| X 点前要走／要下课 | `X-24:00` |
| X 点后才能来 | `0:00-X` |
| 上午 X 点要送／有事（只说一个钟点） | `0:00-(X+1)` |
| 下午 X 点要接／有事（只说一个钟点） | `X-24:00` |
| 只有某几天能来 | 其余工作日 `all` |
| 没写上午下午的 1–7 点 | 当下午（1 点 = 13:00） |

`lunch` 没说时间写 `11:30-14:00 30`；说了时段没说多久，时段不超过 1 小时就写满整个时段，超过 1 小时写 30 分钟。

`prefer_hours` 只写了开始就把结束写成 `18:00`，只写了结束就把开始写成 `9:00`。
